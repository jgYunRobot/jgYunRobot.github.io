## 두산로보틱스

**2024.10–현재 · Robot Dynamics & Motion Control 팀 · 수석연구원**

### 동역학 기반 정지 모션 개발 및 검증

로봇 동역학과 토크·저크 제약을 반영하는 정지 알고리즘을 개발하고, 대표 모델별 63개 조건의 시험과 데이터 분석을 자동화했다.

- **기간:** 2024.10–2025.08
- **역할:** 알고리즘 설계·구현, Safety Board 감시 동기화, 실물 시험·분석 자동화
- 관성–가속도 테이블 방식을 개선하고 현재 동역학에 기반한 정지 시간 산정 구현.
- 정지 중 자세·부하 변화에 대응하는 토크 클램핑과 궤적 시간 조절 구현.
- 제어 궤적과 SS1·SS2 감시 궤적을 동기화하고 정지 시간·거리 실측.

### 차세대 로봇 제어 연산 및 제어 프레임워크 구축

단일팔·양팔·부가축을 공통 모델로 구성하는 연산·제어 기반과 실행 시간 계측 체계를 구축했다.

- **기간:** 2026.04–현재
- **역할:** 로보틱스·제어 라이브러리 설계·구현, 다중 제어점 관리, 실행 구조 개발
- CRBA 기반 관성 행렬 연산을 구현하고 기구학·동역학 결과를 Pinocchio와 교차 검증.
- Frame 기반 로봇 구성, 다중 제어점 목표 관리·명령 라우팅 구현.
- Stage Engine으로 제어 루프를 전환하고 1 ms 주기 기준 기능별 시간 예산·계측·기동 전 검증·로깅 체계 구축.

### Scene Graph 기반 충돌 검사 및 가상 반발력 개발

충돌 후보 선별과 상세 판정을 구성하고, 접촉 정보로 생성한 가상 반발력을 실물 직접교시 환경에서 시연했다.

- **기간:** 2026.01–현재
- **역할:** 충돌 검사 구조 설계, 침투 정보 계산, 반발력 생성·제어 연동
- 로봇·툴·안전영역·장애물의 관계를 표현하는 Scene Graph 구성.
- SAP 기반 후보 선별과 형상별 상세 충돌·침투 벡터 계산 구현.
- 기하 연산 방식 개선, Scene Model/Data 분리와 작업 공간 사전 할당 구조 구현.
- 접촉점 Jacobian으로 가상 반발력을 관절 토크로 변환.

### 부가축 연동 및 여유자유도 제어 개발

외부 서보 드라이버를 EtherCAT으로 연결하고, 개발한 협조·여유자유도 제어를 7축 실물 로봇에 적용·검증했다.

- **기간:** 2025.07–2025.12
- **역할:** 요구사양 작성, 알고리즘 개발, EtherCAT 연동·실물 검증, 프로젝트 리딩
- Linear Base·Positioner와 로봇의 협조 동작 및 Null Space 기반 제어 구현.
- 주 작업을 유지하면서 관절 토크를 최소화하는 보조 목적 구성.
- 작업 종료 시 잔류 운동을 다루는 속도 수준 최적화 방식 개발.

### MuJoCo 기반 물리엔진 시뮬레이터 개발

실물 없이 작업셀 구성, 제어 실행, 궤적 확인을 수행할 수 있는 가상 검증 환경을 구축했다.

- **기간:** 2026.06–2026.09
- **역할:** 가상 제어 환경, 작업셀·물리 상호작용·시각화, 데이터 연동·CI 정비
- 구조물·물체 배치, 씬 초기화, 레이아웃 저장·불러오기 구현.
- 로봇 링크 외력 인가, 물체 파지·고정, TCP 궤적선·로봇 잔상 표시 개발.
- MoveL과 제어 데이터 조회·로그 연동, 양팔 작업셀 예시·외부 서비스 인터페이스 구성.

### 양산 로봇 제어 품질 개선 및 릴리스 대응

제어 결함 22건 해소, V2 백포트 23건, 필드 클레임 6건 출하 승인 종결과 3개 릴리스 라인 전개에 기여했다.

- **기간:** 2024.10–현재
- **역할:** 결함 재현·원인 분석, 모션·제어 알고리즘 수정, 백포트·릴리스 검증
- 조그·트래킹·위빙의 소음·진동, 지령 불연속, 특이점, 정지 모션 발산·오버플로 분석·수정.
- 처짐 보상 속도 feedforward의 해석적 미분·저크 항 분리 처리 구현.
- P3020의 도달 불가능 자세 투영과 관절 지령 연속성 개선.
- V2·V3 버전 간 마이그레이션·백포트와 고객 클레임 대응.

정량 성과의 집계 기간은 2026.01.01–09.07이다.

### 신규 협동로봇 안전인증 대응

안전 정지·Safety Zone 기능의 요구사항을 작성하고 안전인증 대응에 참여했다.

- **기간:** 2025.10–현재
- **역할:** 안전 기능 SR 작성, 안전인증 회의·세미나 참여

### 용접·위빙 제어 구조 리팩토링 및 기능 확장

용접·위빙 구조 개선을 주도하고 신규 파형, 전환·속도 변경·정지·재개 기능을 구현했다.

- **기간:** 2025.09–2025.10
- **역할:** 프로젝트 리딩, 제어 구조 설계·리팩토링, 상태 관리·파형 로직 개발
- 파형 생성·진행 상태·전환을 분리하는 모듈형 구조 설계.
- 삼각파·사다리꼴·지그재그, 파형·주기·각도·offset 변경과 파형 간 전환 구현.
- 위빙 속도 갱신과 일반 모션의 Override 동기화 개선.
- 종료 시 원점 복귀, 중간 정지, 비동기 Pause·Resume 구현.

## 로보스타

**2022.04–2024.10 · 로봇제어 · 사원**

### 컨베이어 트래킹 및 흐름·편심 체결 공정 내재화

이동 물체의 트래킹 모션과 장비 통신·동작 시퀀스를 연결해 흐름·편심 체결 공정을 내재화했다.

- **기간:** 2022.08–2024.10
- **협업:** LG전자 PRI
- **역할:** 트래킹 알고리즘·설정 Wizard, 정밀도 측정, 외부 장비 연동·체결 모션 개발
- 이동 물체 접근·속도 동기화·추종 해제, 트래킹 중 직선·관절 모션 구현.
- 일반 모션과의 Blending, 엔코더 필터와 데이터 지연 오차 보상 개발.
- 비전 트래킹·응용 데모와 비전·PLC·체결 툴 통신 통합.
- 관성·가감속을 고려한 모션과 이동 물체의 편심 구멍 정렬 구현.

### 산업용 로봇 제어기 고도화

궤적 속도 조절과 장애물·특이점 회피를 구현하고, LiDAR 기반 SSM 응용을 2023 Automation World에 전시했다.

- **기간:** 2022.04–2023.12
- **협업:** LG전자 CTO
- **역할:** 6축 로봇의 속도 조절·장애물 회피·특이점 회피 알고리즘 설계·구현
- 경로를 유지하며 속도를 조절하는 Trajectory Dynamic Scaling 구현.
- Potential Field·Admittance 기반 장애물 회피와 기준 궤적 복귀 구현.
- 회피 중 궤적 진행 속도 조절·정지와 특이점 통과 후 복귀 제어 구현.
- 직선·관절 모션 간 Blending 구현.

### 산업용 로봇 제어기 펌웨어 양산 디버깅

자사 로봇 제어기 펌웨어의 양산 오류를 분석하고 디버깅했다.

- **기간:** 2022.04–2024.10
- **역할:** 양산 오류 분석·디버깅

인공지능 교육 도서 집필에 참여하고, 학습 예제 모델과 3축 로봇 Visual Servoing 알고리즘을 개발했다.

- **프로젝트 기간:** 2020.12–2021.08
- **역할:** 도서 집필, 딥러닝·강화학습 예제 개발, 로봇 비전 제어 구현

- YOLO 객체 인식 결과를 활용한 3축 로봇 Visual Servoing 구현.
